Agentic AI Workshop · Day 1

Workshop 1 — Kiro Basic 핸즈온 가이드

AI 기반 개발 환경 Kiro를 사용해, 지능형 AI 에이전트 챗봇이 결합된 완전한 이커머스 웹사이트를 직접 만들어 보는 실습입니다. 자연어 프롬프트만으로 프론트엔드·백엔드·데이터베이스를 갖춘 애플리케이션을 완성합니다.

소요 시간 약 60~90분 Windows · macOS · Linux 난이도 입문

목차

  1. 사전 준비 — Kiro 설치 · 로그인
  2. Task 1 — 작업 폴더 생성
  3. Task 2 — 폴더 열기
  4. Task 3 — 터미널 열고 위치 확인
  5. Task 4 — 실습 환경 준비 (Node · Python · uv)
  6. Lab 5 — Vibe Coding으로 이커머스 앱 만들기
  7. Troubleshooting
  8. 실습 종료
사전 준비 · Prerequisites

시작하기 전에

실습을 시작하기 전에 Kiro IDE를 설치하고 로그인해 둡니다.

1

Kiro IDE 설치

kiro.dev에 접속해 사용 중인 운영체제(Windows / macOS)용 설치 파일을 내려받아 설치합니다.

2

Kiro 로그인

Kiro를 실행한 뒤 안내에 따라 로그인합니다. 로그인이 완료되어야 Vibe Coding 등 AI 기능을 사용할 수 있습니다.

Task 1

작업 폴더 생성 — kiro-vibe

실습에 사용할 빈 작업 폴더 kiro-vibe를 만듭니다. 원하는 위치(예: 홈 디렉터리나 바탕화면)에 생성하세요.

macOSLinux
# 홈 디렉터리에 생성하는 예시
mkdir ~/kiro-vibe
Windows (PowerShell)
# 현재 위치에 생성하는 예시
mkdir kiro-vibe
폴더는 Kiro IDE 안에서 직접 만들 필요는 없습니다. 파인더 / 탐색기에서 만들거나 위 명령으로 만들어도 됩니다. 중요한 것은 비어 있는 폴더라는 점입니다.
Task 2

폴더 열기 — File → Open Folder

  1. Kiro 상단 메뉴에서 File → Open Folder를 선택합니다.
  2. 방금 만든 kiro-vibe 폴더를 선택해 엽니다.
지금 이 폴더에는 아무 것도 없습니다. 이후 Vibe Coding이 이 빈 폴더 안에 애플리케이션 전체를 생성하게 됩니다.
Task 3

터미널 열고 현재 위치 확인

  1. Kiro 상단 메뉴에서 Terminal → New Terminal을 선택해 터미널을 엽니다.
  2. 아래 명령으로 현재 디렉터리 위치가 kiro-vibe 폴더인지 확인합니다.
macOSLinux
pwd
Windows (PowerShell)
# PowerShell
pwd
# 또는 명령 프롬프트(cmd)
cd
출력된 경로의 끝이 ...\kiro-vibe(Windows) 또는 .../kiro-vibe(macOS · Linux)로 끝나면 올바른 위치입니다.
Task 4

실습 환경 준비하기

실습을 진행하려면 아래 구성 요소를 설치 · 설정해야 합니다.

  • Node.js 18.x 이상 — 이커머스 애플리케이션의 프론트엔드 · 백엔드 실행
  • Python 3.8 이상 — 개발 도구 및 백엔드 연동
  • uv — MCP 서버용 고속 Python 패키지 관리자

4.1 Node.js 설치

Node.js는 이커머스 애플리케이션의 백엔드 · 프론트엔드 실행에 필요합니다. nodejs.org에서 LTS 버전(18.x 이상 권장)을 내려받거나 아래 명령으로 설치합니다.

macOS (Homebrew)
brew install node
Linux (Debian · Ubuntu)
# NodeSource LTS 저장소를 통해 설치 (권장)
curl -fsSL https://deb.nodesource.com/setup_lts.x | sudo -E bash -
sudo apt install -y nodejs
Windows는 nodejs.org에서 받은 .msi 설치 파일을 실행해 마법사 안내를 따릅니다.

설치 확인

공통
node --version
npm --version
두 명령 모두 버전 번호가 출력되면 정상 설치된 것입니다.

4.2 Python 설치

Python은 여러 개발 도구와 백엔드 연동에 사용됩니다. python.org에서 3.8 이상을 내려받거나 아래 명령으로 설치합니다.

macOS (Homebrew)
brew install python
Linux (Debian · Ubuntu)
sudo apt install python3 python3-pip python-is-python3
Windows: 설치 프로그램 실행 시 "Add Python to PATH" 체크박스를 반드시 선택하세요.

설치 확인

공통
python --version
pip --version
macOS 참고 — python3 · pip3만 된다면 셸 설정 파일에 별칭을 추가하세요.
macOS (zsh)
echo 'alias python="python3"' >> ~/.zshrc
echo 'alias pip="pip3"' >> ~/.zshrc
적용 후 현재 터미널 창을 닫고 새 터미널을 열면 별칭이 반영됩니다.

4.3 uv 설치

uv는 빠른 Python 패키지 설치 · 의존성 관리 도구로, Kiro가 MCP 서버를 관리할 때 사용합니다.

Windows (PowerShell)
powershell -c "irm https://astral.sh/uv/install.ps1 | iex"
macOSLinux
curl -LsSf https://astral.sh/uv/install.sh | sh

설치 확인

공통
uv --version
⚠️ uv 명령을 찾을 수 없다면, 터미널을 새로 열어서 다시 확인하세요 (PATH 갱신 필요).
Lab 5

Vibe Coding으로 이커머스 웹 애플리케이션 만들기

이 랩에서는 Kiro의 Vibe Coding 기능을 사용해, 자연어 프롬프트만으로 완전한 이커머스 웹사이트를 빠르게 구축합니다.

Vibe Coding이란?

Vibe Coding은 프로젝트 요구사항을 해석해 프론트엔드 · 백엔드 · 데이터베이스를 포함한 전체 애플리케이션 아키텍처를 자동 생성하는 Kiro의 AI 개발 모드입니다. 단순한 코드 생성 수준을 넘어, 비즈니스 로직 · 사용자 경험 패턴 · 기술 모범 사례까지 이해해 구현합니다.

무엇을 만드나요?

3-tier 아키텍처현대적 구조의 이커머스 웹 애플리케이션
React 프론트엔드반응형 UI와 인터랙티브 컴포넌트
Node.js 백엔드RESTful API와 비즈니스 로직
SQL 데이터베이스스키마 설계와 데이터 관계
완전한 사용자 흐름상품 둘러보기부터 장바구니 관리까지

5.1 Kiro 대화창에 다음 프롬프트 입력

Kiro 채팅 입력창에 아래 프롬프트를 붙여 넣고 보냅니다. Kiro가 요구사항을 해석해 애플리케이션 전체를 생성합니다.

▶ Kiro에 입력 (한국어)
세 개의 웹 페이지로 구성된 간단한 이커머스 웹사이트를 만들어줘. 다음을 포함해줘: 1. 홈 페이지: 20개의 샘플 상품 목록 (상품 사진은 이모지로 대체) 2. 상품 페이지: 상품 설명, 가격, 수량, 장바구니 담기 버튼, 그리고 샘플 사용자 리뷰 3. 장바구니 페이지: 구매할 상품 목록, 총 결제 금액, 그리고 수량 변경·항목 삭제 같은 동작 버튼 웹 애플리케이션은 3-tier 아키텍처를 기반으로 해줘: - UI 렌더링을 담당하는 React 기반 프론트엔드 - 장바구니 담기·삭제 등 애플리케이션 로직을 담당하는 Node.js 기반 백엔드 - 상품과 장바구니 항목을 저장하는 SQL 기반 데이터베이스
생성에는 수 분이 걸릴 수 있습니다. Kiro가 파일을 만들고 의존성을 설치하는 동안 진행 상황을 지켜보세요. 중간에 승인 · 실행을 묻는 창이 뜨면 안내에 따라 허용합니다.

5.2 애플리케이션 실행

▶ Kiro에 입력 (한국어)
애플리케이션을 실행해줘

5.3 브라우저에서 확인

이커머스 웹사이트가 웹 브라우저에서 자동으로 열립니다. 자동으로 열리지 않으면 아래 주소로 접속하세요.

브라우저 주소
http://localhost:3000
※ 포트가 3000이 아닐 수 있습니다. Kiro 출력이나 터미널에 표시된 포트 번호로 접속하세요.

5.4 애플리케이션 테스트

  • 상품 둘러보기 — 홈 페이지를 탐색하고 여러 상품을 클릭해 봅니다.
  • 장바구니 담기 — 여러 상품을 장바구니에 담습니다.
  • 장바구니 보기 — 장바구니 페이지로 이동해 담은 항목을 확인합니다.
  • 수량 변경 — 항목 수량을 바꿔 봅니다.
  • 항목 삭제 — 항목 삭제 기능을 테스트합니다.
기능이 제대로 동작하지 않으면, 문제 상황을 그대로 프롬프트로 적어 Kiro에게 보내면 디버깅해 줍니다.
