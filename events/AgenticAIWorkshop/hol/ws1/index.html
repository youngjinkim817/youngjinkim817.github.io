Workshop 1

Kiro Basic

⏱ 예상 시간: 60~90분 📋 태스크: 6개 🎯 Day 1 실습
워크숍 개요

이 실습에서는 Kiro IDE를 처음 설치하고 로그인하는 것부터 시작해, Vibe Coding과 Spec 기반 개발(Spec-Driven Development) 두 가지 AI 코드 생성 방식을 직접 경험합니다.

사전 요구사항
Node.js, Git, Python
학습 목표
Kiro 숙달 + 개발 방식 비교
실습 환경
로컬 개발 환경
1
작업 폴더 생성하기
워크숍 실습 파일을 저장할 전용 폴더를 생성합니다.
macOS — Terminal 명령어
bash 
mkdir -p ~/workshop/kiro-basic
cd ~/workshop/kiro-basic
pwd
Windows — PowerShell 명령어
PowerShell 
New-Item -ItemType Directory -Path "$env:USERPROFILE\workshop\kiro-basic" -Force
cd "$env:USERPROFILE\workshop\kiro-basic"
Get-Location
확인 방법
  • 명령어 실행 후 경로가 출력되면 성공.
💡 팁: 이 폴더는 이번 워크숍에서 생성하는 모든 프로젝트의 루트 폴더가 됩니다. 실습이 끝나면 전체 폴더를 삭제하여 환경을 정리할 수 있습니다.
2
Kiro 설치
kiro.dev에서 Kiro IDE를 다운로드하고 설치합니다.
공통 단계 1 — 다운로드 페이지 접속

브라우저에서 https://kiro.dev에 접속합니다.

공통 단계 2 — 운영체제에 맞는 설치 파일 다운로드

페이지에서 macOS용 다운로드 버튼을 클릭합니다 (.dmg 파일).

macOS 설치 절차
  1. 다운로드된 .dmg 파일을 더블클릭하여 마운트합니다.
  2. Kiro 아이콘을 /Applications 폴더로 드래그합니다.
  3. 마운트된 디스크 이미지를 꺼냅니다(선택 사항).
  4. Launchpad 또는 Spotlight(⌘+Space → "Kiro")로 실행합니다.
⚠️ macOS 보안 정책으로 인해 "개발자를 확인할 수 없습니다" 경고가 뜰 수 있습니다. 시스템 환경설정 → 보안 및 개인정보 보호에서 "허용"을 클릭하면 실행됩니다.

페이지에서 Windows용 다운로드 버튼을 클릭합니다 (.exe 설치 파일).

Windows 설치 절차
  1. 다운로드된 .exe 설치 파일을 더블클릭합니다.
  2. 설치 마법사의 안내를 따라 진행합니다.
  3. 설치가 완료되면 시작 메뉴에서 "Kiro"를 검색하여 실행합니다.
⚠️ Windows Defender SmartScreen이 실행을 차단할 수 있습니다. "추가 정보" → "실행"을 클릭하면 설치가 진행됩니다.
설치 확인
  • Kiro 아이콘을 클릭하면 IDE 창이 실행됩니다.
  • 버전 확인: 메뉴 Help > About Kiro 에서 버전 정보를 확인할 수 있습니다.
3
Kiro 로그인
GitHub, Google, 또는 AWS Builder ID로 로그인합니다.
로그인 단계
  1. Kiro를 실행합니다.
  2. 시작 화면에서 "Sign in" 버튼을 클릭합니다.
  3. 로그인 방법을 선택합니다:
    • GitHub (권장) — 개발자에게 친숙한 방식
    • Google — Google 계정으로 빠른 로그인
    • AWS Builder ID — AWS 기반 통합 인증
  4. 브라우저가 자동으로 열리면 선택한 방법으로 인증을 완료합니다.
  5. 인증 완료 후 Kiro로 돌아와 로그인 상태를 확인합니다.
확인 방법
  • Kiro IDE 좌측 하단에 사용자 아이콘 또는 이름이 표시되면 로그인 성공입니다.
  • Free 플랜으로 이번 실습의 모든 기능을 사용할 수 있습니다.
💡 팁: GitHub 계정을 사용하면 Kiro와의 통합이 가장 원활합니다. 나중에 코드 저장소 연동 시에도 편리합니다.
4
개발 도구 설치 확인
이번 실습에 필요한 개발 도구가 설치되어 있는지 확인합니다.
확인할 도구
🟢
Node.js 18+
React 프론트엔드 및 Node.js 백엔드 실행에 필요
🔷
Git
소스 코드 버전 관리 도구
🐍
Python 3.9+
스크립트 및 데이터 처리 도구
macOS — 설치 버전 확인 (bash)
bash 
node --version      # v18.0.0 이상
npm --version       # 9.0.0 이상
git --version       # git version 2.x.x
python3 --version   # Python 3.9.x 이상
Windows — 설치 버전 확인 (PowerShell)
PowerShell 
node --version
npm --version
git --version
python --version
설치가 필요한 경우

Node.js (macOS)

bash — Homebrew 사용 
brew install node

Homebrew가 없으면 https://nodejs.org 에서 LTS 버전을 다운로드합니다.

Git (macOS)

bash 
brew install git
# 또는 Xcode Command Line Tools 설치
xcode-select --install

Node.js (Windows)

https://nodejs.org 에서 LTS 버전을 다운로드 후 설치합니다.

Git (Windows)

https://git-scm.com 에서 다운로드 후 설치합니다.

확인 방법
  • 모든 버전 명령어가 오류 없이 버전 번호를 출력하면 성공입니다.
  • Node.js는 v18.0.0 이상이어야 합니다.
  • Python은 3.9.x 이상이어야 합니다.
⚠️ Node.js 버전 문제: 이미 구버전 Node.js가 설치되어 있다면 nvm(Node Version Manager)을 사용하여 여러 버전을 병렬 관리하는 것을 권장합니다.
💡 Kiro의 도구 자동 감지: Kiro IDE는 시작 시 시스템에 설치된 Node.js, npm, Python 등의 도구를 자동으로 감지하여 인식합니다. Kiro 내부 터미널에서도 동일한 도구를 사용할 수 있습니다.
5
Vibe Coding으로 전자상거래 웹사이트 생성
Kiro Chat에 자연어 프롬프트를 입력하여 전자상거래 웹사이트를 생성합니다.
💡 Vibe Coding이란? 코드 구조나 아키텍처를 직접 설계하지 않고, 자연어로 원하는 결과를 설명하면 AI가 즉시 코드를 생성하는 방식입니다. 빠른 프로토타이핑에 유용합니다.
Step 1: 작업 폴더 열기
bash — macOS 
mkdir -p ~/workshop/kiro-basic/ecommerce-vibe
cd ~/workshop/kiro-basic/ecommerce-vibe
PowerShell — Windows 
New-Item -ItemType Directory -Path "$env:USERPROFILE\workshop\kiro-basic\ecommerce-vibe" -Force
cd "$env:USERPROFILE\workshop\kiro-basic\ecommerce-vibe"

그런 다음 Kiro에서 File > Open Folder로 이 폴더를 엽니다.

Step 2: Chat 패널에 프롬프트 입력

Kiro의 Chat 패널(사이드바에서 채팅 아이콘 클릭)을 열고 아래 프롬프트를 복사하여 입력합니다.

Kiro Chat 프롬프트 
3개의 웹페이지로 구성된 간단한 전자상거래 웹사이트를 만들어줘.

[페이지 구성]
1. 홈페이지: 이모지로 상품 이미지를 표현한 20개의 샘플 상품 목록
2. 상품 상세 페이지: 상품 설명, 가격, 수량 선택, 장바구니 담기 버튼, 샘플 사용자 리뷰 포함
3. 장바구니 페이지: 구매 예정 상품 목록, 총 금액, 수량 변경 및 삭제 버튼 포함

[아키텍처]
3계층(3-tier) 아키텍처 기반으로 구성:
- 프론트엔드: UI 렌더링을 담당하는 React 기반
- 백엔드: 장바구니 추가·삭제 같은 애플리케이션 로직을 처리하는 Node.js 기반
- 데이터베이스: 상품과 장바구니 항목을 저장하는 SQL 기반
💡 Kiro가 파일을 생성하기 시작하면 Chat 창에서 진행 상황을 확인할 수 있습니다. 생성이 완료될 때까지 기다립니다.
Step 3: 생성된 코드 확인 및 실행
bash — 백엔드 실행 
cd backend && npm install && node server.js &
bash — 프론트엔드 실행 
cd frontend && npm install && npm start
PowerShell — 백엔드 실행 
cd backend; npm install; node server.js
PowerShell — 프론트엔드 실행 (새 창에서) 
cd frontend; npm install; npm start
Step 4: 브라우저에서 결과 확인

브라우저에서 http://localhost:3000에 접속하여 생성된 전자상거래 사이트를 확인합니다.

Vibe Coding 특징 관찰
  • 코드 구조를 사전에 설계하지 않고 결과가 나옵니다.
  • 빠르지만 아키텍처가 최적화되지 않을 수 있습니다.
  • 복잡한 요구사항에서 일관성이 떨어질 수 있습니다.
6
Spec 기반으로 전자상거래 앱 생성
Kiro Spec 모드를 사용하여 체계적인 요구사항-설계-구현 프로세스로 동일한 전자상거래 앱을 만들어봅니다. Vibe Coding과 비교하여 품질 차이를 확인합니다.
💡 Spec-Driven Development란? Requirements(요구사항) → Design(설계) → Tasks(구현 태스크)의 단계적 프로세스로 코드를 생성합니다. 대규모 프로젝트와 팀 협업에 적합합니다.
Step 1: 새 작업 폴더 생성
bash — macOS 
mkdir -p ~/workshop/kiro-basic/ecommerce-spec
cd ~/workshop/kiro-basic/ecommerce-spec
PowerShell — Windows 
New-Item -ItemType Directory -Path "$env:USERPROFILE\workshop\kiro-basic\ecommerce-spec" -Force
cd "$env:USERPROFILE\workshop\kiro-basic\ecommerce-spec"

Kiro에서 File > Open Folder로 이 폴더를 엽니다.

Step 2: Kiro Spec 시작
  1. 좌측 패널에서 Spec 아이콘을 클릭합니다.
    또는 Cmd+Shift+P → "Kiro: New Spec" 실행 (Windows: Ctrl+Shift+P)
  2. "New Spec" 버튼을 클릭합니다.
Step 3: Spec 프롬프트 입력

Task 5와 동일한 프롬프트를 입력합니다.

Kiro Spec 프롬프트 
3개의 웹페이지로 구성된 간단한 전자상거래 웹사이트를 만들어줘.

[페이지 구성]
1. 홈페이지: 이모지로 상품 이미지를 표현한 20개의 샘플 상품 목록
2. 상품 상세 페이지: 상품 설명, 가격, 수량 선택, 장바구니 담기 버튼, 샘플 사용자 리뷰 포함
3. 장바구니 페이지: 구매 예정 상품 목록, 총 금액, 수량 변경 및 삭제 버튼 포함

[아키텍처]
3계층(3-tier) 아키텍처 기반으로 구성:
- 프론트엔드: UI 렌더링을 담당하는 React 기반
- 백엔드: 장바구니 추가·삭제 같은 애플리케이션 로직을 처리하는 Node.js 기반
- 데이터베이스: 상품과 장바구니 항목을 저장하는 SQL 기반
Step 4: Requirements 검토
  1. Kiro가 자동으로 요구사항 문서(requirements.md)를 생성합니다.
  2. 내용을 읽고 필요하면 수정합니다.
  3. 검토 완료 후 "Approve" 버튼을 클릭합니다.
💡 팁: Requirements 단계에서 누락된 기능이나 모호한 요구사항을 발견하면 직접 문서를 수정하여 명확하게 만들 수 있습니다. 이것이 Spec 기반 개발의 핵심 가치입니다.
Step 5: Design 검토
  1. Kiro가 시스템 아키텍처, 데이터 모델, API 설계 문서를 자동 생성합니다.
  2. 설계 내용을 검토합니다.
  3. 확인 후 "Approve" 버튼을 클릭합니다.
Step 6: Tasks 실행
  1. Kiro가 구체적인 구현 태스크 목록을 생성합니다.
  2. "Run All Tasks"를 클릭하거나 각 태스크를 순서대로 실행합니다.
  3. 각 태스크가 완료될 때마다 코드가 생성됩니다.
Step 7: 결과 실행 및 확인
bash — 백엔드 실행 
cd backend && npm install && node server.js &
bash — 프론트엔드 실행 
cd frontend && npm install && npm start
PowerShell — 백엔드 실행 
cd backend; npm install; Start-Process powershell { node server.js }
PowerShell — 프론트엔드 실행 
cd frontend; npm install; npm start
Step 8: Vibe Coding 결과와 비교

두 방식의 결과를 비교하며 차이점을 확인합니다.

비교 항목 Vibe Coding Spec-Driven
개발 속도 빠름 상대적으로 느림
코드 구조 가변적 체계적
요구사항 추적 없음 문서화됨
대형 프로젝트 적합성 낮음 높음
팀 협업 어려움 용이
유지보수성 어려움(구조 파악 필요) 용이(문서 기반 파악 가능)
💡 결론: Vibe Coding은 빠른 프로토타이핑에, Spec-Driven Development는 복잡하고 장기적인 프로젝트에 적합합니다. Kiro는 두 방식을 모두 지원하여 상황에 따라 유연하게 선택할 수 있습니다.
