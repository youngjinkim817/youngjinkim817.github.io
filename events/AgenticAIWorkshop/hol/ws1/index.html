Agentic AI Workshop · Workshop 1

Kiro Basic

Kiro를 설치하고 로그인한 후, Vibe Coding으로 전자상거래 웹사이트를 빠르게 생성하고, Spec-Driven Development로 쇼핑 어시스턴트 챗봇을 구축합니다. 이 워크숍에서는 AWS 접속 없이 로컬 환경에서 모든 실습을 진행합니다.

⏱ 약 90분 🏠 로컬 환경 🛒 전자상거래 앱 🤖 쇼핑 챗봇
1

작업 폴더 생성

이번 워크숍에서 사용할 로컬 작업 디렉토리를 생성합니다.

1
터미널 열기

macOS: Cmd + Space → Terminal 검색 후 실행
Windows: Win + R → cmd 또는 PowerShell 실행

2
작업 디렉토리 생성 및 이동

아래 명령어를 실행하여 워크숍 폴더를 생성합니다.

# 워크숍 작업 폴더 생성 및 이동 mkdir -p ~/workshop/kiro-basic && cd ~/workshop/kiro-basic
💡 팁
-p 옵션은 중간 디렉토리가 없어도 자동으로 생성합니다. workshop 폴더와 kiro-basic 폴더가 한 번에 만들어집니다.
3
생성 확인

폴더가 정상적으로 생성되었는지 확인합니다.

# 현재 위치 확인 pwd # 예상 출력: /Users/<username>/workshop/kiro-basic
2

Kiro 설치

kiro.dev에서 Kiro IDE를 다운로드하고 설치합니다.

1
Kiro 공식 사이트에서 다운로드

브라우저에서 kiro.dev에 접속하여 운영체제에 맞는 설치 파일을 다운로드합니다.

🔗 다운로드 링크
https://kiro.dev — 메인 페이지의 Download 버튼을 클릭하면 OS를 자동 감지합니다.

macOS 설치 방법:

  1. .dmg 파일 다운로드 완료 후 파일을 더블클릭
  2. 열린 창에서 Kiro 아이콘을 Applications 폴더로 드래그
  3. Applications에서 Kiro 실행 — 처음 실행 시 "확인되지 않은 개발자" 경고가 뜨면:
# 보안 정책으로 막힌 경우 터미널에서 실행 xattr -cr /Applications/Kiro.app
💡 Apple Silicon (M1/M2/M3)
Apple Silicon Mac에서는 arm64 빌드를 다운로드하면 더 빠르게 실행됩니다.

Windows 설치 방법:

  1. Kiro-Setup-x.x.x.exe 인스톨러 파일 다운로드
  2. 다운로드된 .exe 파일을 더블클릭하여 실행
  3. UAC(사용자 계정 컨트롤) 팝업에서 "예" 클릭
  4. 설치 마법사 안내에 따라 진행 → "Install" 클릭
  5. 설치 완료 후 "Launch Kiro" 체크 → "Finish"
⚠️ Windows Defender SmartScreen
"Windows에서 PC를 보호했습니다" 경고 시 "추가 정보" → "실행"을 클릭합니다.
2
Kiro 실행 확인

Kiro를 실행하면 환영 화면(Welcome 탭)이 표시되어야 합니다. 정상 실행되면 설치가 완료된 것입니다.

ℹ️ 참고
Kiro는 VS Code 기반의 에이전틱 AI IDE입니다. 처음 실행 시 필요한 언어 확장(extensions)을 자동으로 설치하며, 이 과정에 수 분이 소요될 수 있습니다.
3

Kiro 로그인

GitHub 계정으로 Kiro에 로그인하고 무료 플랜을 활성화합니다.

1
Kiro 실행 후 로그인 화면으로 이동

Kiro가 실행되면 환영 화면에서 "Sign in" 버튼을 클릭합니다. 또는 왼쪽 하단의 계정 아이콘(👤)을 클릭해도 됩니다.

2
GitHub 계정으로 인증

로그인 방법을 선택하는 화면에서 "Continue with GitHub"를 클릭합니다.

  1. 브라우저가 자동으로 열리며 GitHub OAuth 인증 페이지로 이동
  2. GitHub 계정 자격 증명(이메일/비밀번호)으로 로그인
  3. "Authorize Kiro" 버튼 클릭하여 권한 부여
  4. 브라우저에 "You can now close this tab" 메시지가 표시되면 완료
⚠️ GitHub 계정 없는 경우
github.com/signup에서 무료 계정을 먼저 생성하세요. 이메일 인증까지 완료해야 합니다.
3
무료 플랜 확인

로그인 완료 후 Kiro 왼쪽 하단에 GitHub 사용자 이름이 표시됩니다. 무료(Free) 플랜은 월 50회 에이전트 요청을 포함하며, 이번 워크숍에 충분합니다.

💡 플랜 확인 방법
Kiro 하단의 계정 이름 클릭 → "Manage Subscription"에서 현재 플랜과 사용량을 확인할 수 있습니다.
4
로그인 완료 확인

Kiro 메인 화면에서 Chat 패널(채팅 아이콘)이 활성화되고 프롬프트 입력창이 표시되면 로그인이 성공적으로 완료된 것입니다.

4

개발 도구 설치 확인

워크숍에 필요한 Node.js, Python, Git 버전을 확인합니다.

1
필수 도구 버전 확인

터미널에서 아래 명령어를 실행하여 각 도구의 버전을 확인합니다.

도구 확인 명령어 필요 버전
Node.js node --version v18.0 이상
Python python3 --version v3.9 이상
Git git --version v2.x 이상
# 한 번에 모든 버전 확인 node --version && python3 --version && git --version
2
미설치 도구 설치 가이드

설치되지 않은 도구가 있으면 아래 공식 링크에서 설치합니다.

🟢 Node.js
nodejs.org에서 LTS 버전(v20 권장)을 다운로드합니다. macOS는 brew install node도 가능합니다.
🐍 Python
python.org/downloads에서 Python 3.11+ 다운로드. macOS는 brew install python3도 가능합니다.
🐙 Git
git-scm.com/downloads에서 다운로드. macOS는 Xcode Command Line Tools(xcode-select --install)에 포함됩니다.
3
npm 버전 확인 (Node.js와 함께 설치)
# npm 버전 확인 (v9 이상 권장) npm --version
5

Vibe Coding으로 전자상거래 웹사이트 생성

Kiro Chat 패널에 자연어 프롬프트를 입력하여 3페이지 이커머스 사이트를 즉시 생성합니다.

1
작업 폴더 생성 및 Kiro에서 열기

Vibe Coding용 프로젝트 폴더를 생성하고 Kiro에서 엽니다.

# ecommerce-vibe 폴더 생성 mkdir -p ~/workshop/kiro-basic/ecommerce-vibe cd ~/workshop/kiro-basic/ecommerce-vibe

Kiro 메뉴에서 File → Open Folder를 선택하고 ~/workshop/kiro-basic/ecommerce-vibe 폴더를 엽니다.

2
Kiro Chat 패널 열기

Kiro 왼쪽 액티비티 바에서 채팅 아이콘(💬)을 클릭하거나, 단축키 Ctrl+Shift+K (macOS: Cmd+Shift+K)로 Chat 패널을 엽니다.

💡 Vibe Coding 모드
Chat 패널의 입력창 상단에 "Chat" 모드가 선택되어 있는지 확인합니다. 이 모드에서 자연어 명령으로 코드를 자동 생성합니다.
3
아래 프롬프트를 Chat 패널에 입력

아래 프롬프트를 복사하여 Kiro Chat 패널의 입력창에 붙여넣고 Enter를 누릅니다.

💬 Kiro Chat 프롬프트 
3개의 웹페이지로 구성된 간단한 전자상거래(이커머스) 웹사이트를 만들어줘. 페이지 구성: 1. 홈페이지: 상품 목록 (6개 상품 카드) 2. 상품 상세 페이지: 이미지, 설명, 가격, 장바구니 담기 버튼 3. 장바구니 페이지: 담긴 상품 목록, 수량 조절, 총 금액, 결제 버튼. HTML/CSS/JavaScript만 사용하고 외부 의존성 없이 구현해줘.
ℹ️ Kiro가 생성하는 파일들
Kiro는 자동으로 index.html, product.html, cart.html, style.css, app.js 등의 파일을 생성합니다. 파일 변경 제안이 나타나면 "Accept All"을 클릭합니다.
4
생성된 웹사이트 실행 및 확인

Kiro가 파일 생성을 완료하면 아래 방법 중 하나로 웹사이트를 실행합니다.

방법 1: 직접 브라우저 열기 (macOS)
open ~/workshop/kiro-basic/ecommerce-vibe/index.html
방법 2: Kiro 내장 브라우저 미리보기
index.html 파일 우클릭 → "Open with Live Preview"
방법 3: VS Code Live Server 확장 사용
Kiro 확장 마켓에서 "Live Server" 검색 → 설치 후 index.html에서 우클릭 → "Open with Live Server"
⚠️ 확인 사항
브라우저에서 홈페이지(상품 6개), 상품 상세 페이지, 장바구니 페이지가 모두 작동하는지 확인합니다. 장바구니 담기 → 장바구니 페이지에서 수량 조절 → 총 금액 변경까지 테스트합니다.
6

Spec-Driven Development로 쇼핑 어시스턴트 챗봇 추가

Kiro의 Spec 모드로 Requirements → Design → Tasks 프로세스를 통해 구조적으로 쇼핑 챗봇 서비스를 구축합니다.

1
새 프로젝트 폴더 생성 및 Kiro에서 열기

Spec 기반 개발을 위한 별도 프로젝트 폴더를 생성합니다.

# ecommerce-spec 폴더 생성 mkdir -p ~/workshop/kiro-basic/ecommerce-spec cd ~/workshop/kiro-basic/ecommerce-spec

Kiro에서 File → Open Folder로 ecommerce-spec 폴더를 엽니다.

2
Kiro Spec 모드로 전환

Chat 패널 상단의 드롭다운에서 "Spec"을 선택하거나, 사이드바의 Spec 아이콘(📋)을 클릭합니다.

ℹ️ Spec 모드란?
Spec(Specification) 모드는 단순 코드 생성이 아닌, 요구사항 → 설계 → 태스크 단계를 거쳐 복잡한 시스템을 구조적으로 개발하는 Kiro의 핵심 기능입니다.
📋
Requirements
기능 요구사항 정의 및 사용자 스토리 작성
🎨
Design
아키텍처, API, 데이터 모델 설계
✅
Tasks
구체적 구현 태스크 목록 자동 생성
3
3계층 아키텍처 이해

구축할 쇼핑 어시스턴트 챗봇 서비스의 구조입니다.

3-Tier Architecture
⚛️
Frontend
React + 팝업 챗봇 UI
↔️
🟢
Backend
Node.js + Strands Agents
↔️
🗄️
Database
SQLite (상품·장바구니·주문)
🤖
Chatbot Engine
Strands Agents + Bedrock Nova Pro
4
Requirements 작성 — 아래 프롬프트 입력

Kiro Spec 패널의 Requirements 단계에서 아래 프롬프트를 입력하고 생성합니다.

📋 Spec Requirements 프롬프트 
Strands Agents SDK를 기반으로 하고, 기반 LLM으로 Bedrock Nova Pro를 사용하는 쇼핑 어시스턴트 챗봇 서비스를 구축해줘. 웹 애플리케이션은 3계층(3-tier) 아키텍처로 구성: - 프론트엔드: React 기반 UI (팝업 챗봇 포함) - 백엔드: Node.js 기반 애플리케이션 로직 - 데이터베이스: SQLite 기반 (상품, 장바구니, 주문 관리). 챗봇 기능: 주문조회, 수량변경, 주문취소, 결제, 주문내역 확인
💡 진행 순서
Kiro가 Requirements 문서를 자동 생성합니다. 내용을 검토한 후 "Approve"를 클릭하면 다음 단계(Design)로 넘어갑니다.
5
Design → Tasks 프로세스 진행

Requirements 승인 후 Design과 Tasks 단계를 순서대로 진행합니다.

2단계: Design
Kiro가 시스템 아키텍처, API 엔드포인트, 데이터베이스 스키마를 자동 설계합니다. 생성된 설계 문서를 검토하고 "Approve Design"을 클릭합니다.
3단계: Tasks
Kiro가 구현 태스크 목록을 자동 생성합니다. 각 태스크는 순서가 있으며, Kiro가 자동으로 실행합니다.
6
각 Task 실행 및 검토

Tasks 단계에서 각 태스크 옆의 ▶ Run 버튼을 클릭하여 순서대로 실행합니다.

예상 태스크 목록 (Kiro가 자동 생성):
  • SQLite 데이터베이스 설정 및 스키마 생성
  • Node.js 백엔드 서버 및 REST API 구현
  • Strands Agents SDK 챗봇 엔진 구현
  • React 프론트엔드 UI 구성
  • 팝업 챗봇 컴포넌트 구현
  • 프론트엔드-백엔드 API 통합
⚠️ AWS 자격 증명 필요 (Bedrock Nova Pro)
챗봇이 Bedrock Nova Pro를 사용하므로 AWS 자격 증명이 필요합니다. 환경 변수로 설정합니다:
# AWS 자격 증명 환경 변수 설정 export AWS_ACCESS_KEY_ID="your-access-key" export AWS_SECRET_ACCESS_KEY="your-secret-key" export AWS_DEFAULT_REGION="us-east-1"
💡 완료 후 실행
모든 태스크 완료 후 터미널에서 아래 명령으로 앱을 실행합니다:
# 백엔드 서버 시작 cd ~/workshop/kiro-basic/ecommerce-spec && npm install && npm start # 브라우저에서 http://localhost:3000 접속
🎉
