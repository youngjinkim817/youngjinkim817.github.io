실행 모드 — Autopilot · Supervised

채팅 패널의 동작 방식 스위치 — 파일 수정 승인 방식을 선택합니다.

🚀 Autopilot — 기본

  • 파일 생성·수정을 단계 승인 없이 진행
  • 결과 확인 후 대화로 조정
  • 실습 기본 설정 — 신속한 진행
VS

🔍 Supervised — 검토형

  • 파일 수정이 포함된 턴마다 승인
  • 변경 사항을 조각 단위로 수락·거부
  • 민감한 데이터·운영 작업에 적합
⚠️ CAUTION   Autopilot에서도 명령 실행 등은 승인 창(Allow)이 별도로 표시됩니다 — 「모든 명령 허용」 설정은 사용하지 않습니다.

Requirements

모호한 프로젝트를 검증 가능한 요구사항으로 변환. "무엇을 만들 것인가"를 확정.
핵심 동작
  • 사용자 스토리·수용 기준 도출
  • 기능·제약을 명시적으로 분리
  • 개발자와 범위(scope) 합의
입력 ▸ 자연어 + 도메인 컨텍스트
출력 ▸ requirements.md

Design

요구사항을 바탕으로 시스템 구조·데이터·인터페이스를 설계.
핵심 동작
  • 아키텍처·데이터 모델·인터페이스 설계
  • 컴포넌트 관계와 흐름 명시
  • 기술 선택 근거를 문서로 기록
입력 ▸ requirements.md
출력 ▸ design.md

Tasks

설계를 작고 검증 가능한 태스크로 나눠 하나씩 구현.
핵심 동작
  • 검증 가능한 태스크로 분할
  • 에이전트가 순차/병렬 구현
  • 개발자가 각 산출물 검토·승인
입력 ▸ design.md

Steering

프로젝트 규칙
프로젝트 지식·규칙을 정의해, 세션 내내 매 대화에서 Kiro가 자동 참고하게 합니다.
동작 방식
  • 지식·규칙을 정의 → 매 대화에서 자동 참고
  • 코드·API·테스트가 팀 규칙을 따라 일관 생성
  • 포함 방식: 항상·조건부(fileMatch)·수동·자동
  • Global(~/.kiro) 또는 Workspace(.kiro) — Workspace 우선
  • 기본 3파일: product.md · tech.md · structure.md

MCP

외부 도구 연동
Model Context Protocol — 에이전트가 외부 도구와 표준 방식으로 통신하는 오픈 프로토콜.
동작 방식
  • 외부 도구와 표준 방식으로 통신 (오픈 프로토콜)
  • AWS 서비스·문서 연동 (조회·관리·비용 분석)
  • Outlook·Jira 등 업무 시스템 연동
  • 셸·CLI·파일 R/W는 내장 도구 (MCP 불필요)
예시 · .kiro/settings/mcp.json
{ "mcpServers": { "aws-docs": { "command": "uvx", "args": ["awslabs.aws-documentation-mcp-server"] } } }

Skills

작업 절차 패키지
반복 작업 절차를 패키지로 묶어 로드합니다. 평소엔 이름·설명만, 수행 시 전체 지침 로드.
동작 방식
  • 반복 절차를 패키지로 묶어 재사용
  • description이 요청과 매칭되면 자동 활성화 (수동 /skill 호출도 가능)
  • 수행 시 전체 지침 로드 — 평소엔 이름·설명만(컨텍스트 절약)
  • open Agent Skills 표준 — 도구·팀 간 이식 가능
예시 · SKILL.md
# .kiro/skills/pr-review/SKILL.md --- name: pr-review description: Review PRs for quality & security. --- ## Review process 1. Check security 2. Error handling

Agent Hook

이벤트 자동화
"파일 저장"·"도구 호출" 등 이벤트 시 에이전트에 작업을 자동 위임, 백그라운드 자율 실행.
동작 방식
  • 이벤트 시 에이전트에 작업 자동 위임
  • 백그라운드 자율 실행 — 문서·테스트·최적화 자동화
  • 사람이 매번 지시할 필요 없음
  • when(트리거) · then(위임 작업) 구조
예시 · .kiro/hooks/*.kiro.hook
{ "name": "저장 시 린트", "when": { "type": "fileEdited", "patterns": ["src/**/*.ts"] }, "then": { "type": "askAgent", "prompt": "변경 파일을 린트·수정" } }
