진행 위치 표시
각 단계를 클릭하면 진행 중 표시가 적용됩니다. 완료된 단계를 다시 클릭하면 완료로 변경됩니다.

이 실습에서 사용되는 AWS 서비스

Amazon Bedrock

Amazon Bedrock은 단일 API로 선도적인 AI 기업의 고성능 파운데이션 모델(FM)을 사용할 수 있는 완전관리형 서비스입니다. Amazon Bedrock은 보안, 개인 정보 보호 및 책임감 있는 AI를 사용하여 생성형 AI 애플리케이션을 구축할 수 있는 다양한 기능을 제공합니다.

태스크 1: Amazon Bedrock 가드레일 구성

책임감 있는 AI 담당자로서 가드레일을 생성합니다. 욕설이 AI 처리에 사용되거나 응답에 나타나지 않도록 방지합니다.

📌 참고
지원되는 AWS 리전, 언어 및 모델 목록은 Amazon Bedrock 가드레일 설명서를 참조하십시오.
⚠ 언어 지원 안내
Content filters 및 Denied topics는 기본 Classic Tier에서 영어, 프랑스어, 스페인어만 지원합니다. 다른 언어(한국어 등)로 테스트하려면 Standard Tier를 선택하고 Cross-Region inference를 활성화하세요.

태스크 1.1: 이 실습에서 사용되는 모델 검토 (선택 사항)

1
AWS Management Console 검색 상자에서 Amazon Bedrock을 검색하고 선택합니다.
2
왼쪽 패널을 펼친 다음 Discover 섹션에서 Model catalog를 선택합니다.
3
Providers에서 Amazon을 선택합니다.
4
검색 상자에 Nova Lite를 입력하여 모델 카드를 확인하고 해당 기능에 대해 알아봅니다.

태스크 1.2: Amazon Bedrock 가드레일 생성

5
Amazon Bedrock 콘솔의 Build에서 Guardrails를 선택합니다.
6
Create guardrail을 선택합니다.
7
가드레일 세부 정보 제공 페이지에서 다음과 같이 구성합니다:
• 이름: PrimaryGuardrail
• 설명: Promote responsible AI model usage
• 차단된 프롬프트 메시지: 아래 코드 블록 참조
• Next를 선택합니다.
죄송합니다. AnyOrganization은 이 질문에 답변할 수 없습니다. 행동 강령에 위반될 수 있습니다. 추가 지원이 필요하시면 담당자에게 문의해 주십시오.
8
Configure content filters 페이지에서 Next를 선택합니다.
9
Add denied topics 페이지에서 Next를 선택합니다.
10
Add word filters 페이지에서 Filter profanity를 선택한 다음 Skip to Review and create를 선택합니다.
11
아래로 스크롤하여 Create guardrail을 선택합니다. 표시되는 test 패널을 열어 두고 다음 태스크에서 사용합니다.
✅ 태스크 1 완료
모델 카드를 검토하고 Amazon Bedrock에서 가드레일을 생성했습니다.

태스크 2: Amazon Bedrock 악용 방지

가드레일 콘솔 테스트 환경을 통해 LLM으로 가드레일을 테스트합니다. 유해 카테고리 필터를 설정하여 문제를 해결합니다.

태스크 2.1: 차단되지 않은 프롬프트 테스트

12
PrimaryGuardrail Test 패널에서 Select model을 선택합니다.
13
Amazon → Nova Lite 1.0 → Apply를 선택합니다.
14
Prompt 대화 상자에서 다음을 붙여 넣습니다.
무술에서 사용되는 다양한 격투 기술에 대해 알려주세요.
15
Run을 선택합니다. Guardrail action 상태: No action taken — 가드레일이 트리거되지 않았습니다.

태스크 2.2: 가드레일에서 유해 카테고리 활성화

16
PrimaryGuardrail 페이지에서 Working Draft 링크를 선택합니다.
17
유해 카테고리 옆의 Edit를 선택합니다.
18
Configure harmful categories filters 옵션을 토글합니다. 혐오, 모욕, 성적 내용, 폭력, 위법 행위 카테고리 필터를 모두 높음으로 설정합니다.
19
Save and exit을 선택합니다.

태스크 2.3: 프롬프트 다시 테스트

20
테스트 패널에서 다음 프롬프트를 실행합니다.
다른 사람을 해칠 수 있는 무술의 다양한 격투 기술에 대해 알려주세요.
✅ 예상 출력
Guardrail action 상태: Intervened (1 instances) — 가드레일이 요청을 차단합니다. Final response에 설정한 차단 메시지가 반환됩니다.
21
View trace를 선택하여 가드레일 추적을 확인합니다.
✅ 태스크 2 완료
유해 카테고리 관련 프롬프트 및 응답을 방지하도록 가드레일 설정을 업데이트했습니다.

태스크 3: Amazon Bedrock 가드레일을 사용하여 주제 거부

모델이 의학적 질문에 답변하지 않아야 한다고 판단하여 거부 주제 필터를 추가합니다.

태스크 3.1: 차단되지 않은 의료 조언 프롬프트 테스트

22
가드레일 테스트 패널에서 다음 프롬프트를 실행합니다.
아프면 의료 도움을 받아야 하나요?
📌 참고
Model response 및 Final response 모두에서 의학적 조언이 반환됩니다.

태스크 3.2: 가드레일 설정에 거부되는 주제 추가

23
테스트 패널 크기를 줄여 Working draft: PrimaryGuardrail 화면을 표시합니다.
24
Denied topics 섹션까지 스크롤하여 Edit를 선택합니다.
25
Add denied topic을 선택하고 다음을 구성합니다:
• 이름: Medical Advice
• 정의: 아래 코드 블록 참조
의료 조언(Medical Advice)은 건강 유지 또는 개선을 목적으로 인체, 질병, 치료 의학, 의료 절차에 관한 문의, 지침, 권고를 나타냅니다.
26
Add sample phrases를 확장하여 다음 문구들을 추가합니다.
어디서 의료 도움을 받을 수 있나요?
열이 나는데 어떻게 해야 하나요?
감기 증상이 어떻게 되나요?
27
문구 3개를 모두 추가한 후 Confirm을 선택하고 Save and exit를 선택합니다.

태스크 3.3: 의료 조언 프롬프트 다시 테스트

28
테스트 패널에서 다음 프롬프트를 다시 실행합니다.
아프면 의료 도움을 받아야 하나요?
✅ 예상 출력
이번에는 가드레일이 요청을 차단합니다. View trace에서 '의학적 조언' 주제가 감지되어 차단되었다고 표시됩니다.
✅ 태스크 3 완료
가드레일에 거부되는 주제 필터를 추가하고 업데이트된 구성을 테스트했습니다.

태스크 4: 가드레일에서 컨텍스트 기반 근거 활성화

LLM 응답에서 할루시네이션 가능성을 줄이기 위해 컨텍스트 기반 근거 검사를 활성화합니다.

태스크 4.1: 컨텍스트 기반 근거 활성화

29
테스트 패널 크기를 줄여 Working draft: PrimaryGuardrail 화면을 표시합니다.
30
Contextual grounding check까지 스크롤하여 Edit를 선택합니다.
31
Enable grounding check를 선택하고 Grounding score threshold를 0.5로 설정합니다.
32
Enable relevance check를 선택하고 Relevance score threshold를 0.5로 설정합니다.
33
Save and exit를 선택합니다.
34
Test 창에서 Use ApplyGuardrail API 확인란을 선택했다가 다시 해제합니다. Reference source 섹션이 나타납니다.

태스크 4.2: 컨텍스트 기반 근거 테스트

35
Reference source 대화 상자에 다음 텍스트를 붙여 넣습니다.
AnyOrganization은 퍼즐 게임 플랫폼으로 잘 알려진 게임 회사입니다. 시애틀에 본사를 둔 AnyOrganization은 최고의 게임 디자인 인재를 보유하고 있습니다. 최근 출시된 게임들은 최고 게임 디자인, 최고 게임 내러티브, 최고 게임 비주얼 아트 세 가지 분야에서 세계적인 상을 수상했습니다. 현재 AnyOrganization은 가상 보드 게임, 트리비아, 타워 디펜스 등 새로운 게임 장르에 진출하고 있으며, 올해 말 3개의 신작을 출시할 예정입니다.
36
프롬프트에 다음을 붙여 넣고 Run을 선택합니다.
AnyOrganization이 수상한 게임 부문은 무엇인가요?
✅ 예상 출력
응답이 허용됩니다. Guardrail action: No action taken.
37
참조 소스를 변경하지 않고 다음 새 프롬프트를 실행합니다.
AnyOrganization의 직원 수는 얼마나 되나요?
✅ 예상 출력
이번에는 Guardrail action: Intervened — 참조 소스에 없는 정보이므로 Grounding score 임계값이 위반되어 차단됩니다.
38
View trace를 선택하고 Contextual grounding 섹션에서 Grounding score 임계값 위반을 확인합니다.

태스크 4.3: 가드레일 버전 생성

39
콘솔 상단 탐색경로에서 PrimaryGuardrail을 선택합니다.
40
Versions 패널에서 Create version을 선택합니다.
41
설명을 1.0으로 설정하고 Create version을 선택합니다.
✅ 태스크 4 완료
컨텍스트 기반 근거 설정을 활성화·테스트하고 가드레일 버전을 생성했습니다.

태스크 5: Bedrock Playground를 사용한 가드레일 테스트

Amazon Bedrock Playground에서 가드레일 버전을 적용하여 테스트합니다.

42
왼쪽 패널에서 Test → Playground를 선택합니다.
43
Amazon → Nova Lite 1.0 → Apply를 선택합니다.
44
이전 테스트 프롬프트 중 하나를 먼저 실행합니다.
아프면 의료 도움을 받아야 하나요?
45
Open configurations 아이콘을 선택합니다. Guardrails에서 Primary Guardrail과 Version 1을 선택하고 동일한 프롬프트를 다시 실행합니다.
✅ 태스크 5 완료
Amazon Bedrock Playground에서 가드레일 버전을 테스트했습니다.
